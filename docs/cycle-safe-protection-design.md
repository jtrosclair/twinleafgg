# Cycle-safe protection: design and unresolved work

Status: research only. No production evaluator or blanket cache is safe for the current open-ended reducer model. The existing experimental Ancient Star guard, under the separate scratch manifest, must remain unwired. It passed targeted Corviknight, Enamorus, and nested-action tests but its cost grows factorially for artificially duplicated active sources.

The real Store accepts reducers that distinguish the exact source card, change answers during a turn, call nested Ability actions, mutate game state, and emit external side effects. `fixtures/source-dependent-protection.spec.fixture.ts` gives two minimal, reproducible examples independent of the experimental guard. A target-only cache, cache shared across events, clone-based dry run, or suppression of the same-target genuine action silently alters behavior. State cloning cannot roll back an external closure. The original recursion is not made safe by these observations.

A possible bounded implementation requires changing the contract, not merely adding a memo map:

1. Register an exact, explicitly audited capability for each live reducer that can take part in suppression/protection; unknown reducer, subclass, instance override or unclassified event requires falling back to the existing behavior. A capability must establish data-only evaluation with no state mutation, callback, random draw, prompt, external effect, or nested real action; purity must cover transitive dependencies, including tool, stadium and energy checks. Exact identity and engine version matter, not a string card name.
2. Capture an immutable rule snapshot and construct a dependency graph whose nodes carry physical source identity, target identity, owner, effect kind, Ability/protection identity, and every relevant piece of state. Include independent suppressors such as Path and external protection such as Hood. Enamorus excludes all Enamorus V before its own protection check. Actual `PowerEffect` actions remain on the normal event path and are never identified as probes by name.
3. For the fully certified subgraph, memoize only within one immutable snapshot and evaluate dependency components once. A cycle is not automatically false or true: only resolve components for which a separately tested game rule defines an outcome, such as the Corviknight self-protection interaction against an opponent's Pokémon Ability. Otherwise return an explicit unknown result and preserve the legacy path. Do not dispatch legacy reducers while constructing this graph; doing so reintroduces side effects and recursion.
4. Invalidate the whole result on every relevant mutation or start a fresh snapshot for each top-level operation. Do not reuse across nested real actions. If eligibility can change during the action, abort the optimization before it executes and use the original path. Replaying fewer legacy reducer invocations is not equivalent if any observer can see them; the contract must explicitly migrate those observers, or the optimized path must stay disabled.

The fallback preserves existing behavior only; it does not fix an already-cyclic legacy game state. A universal bounded algorithm cannot promise both termination and observational equivalence to arbitrary stateful reducers, which can themselves issue unbounded nested actions. Safely fixing every such position therefore requires migrating those reducers or deciding explicit error semantics for unsupported cycles. Neither is complete in this research.

Required proof before wiring: immutable-snapshot validation and exact participant registry; genuine nested action and same-target reentrancy; separate physical sources with different protection; alternating/stateful and closure observers; exception cleanup and multiple stores; Corviknight with and without independent locks and Hood; Enamorus with and without Psychic Energy and protected Enamorus; multiple active sources and unusual puzzle payloads; every existing suppression family; and saved puzzle/action plus win-condition regression comparisons on the final frozen source. The existing `/private/tmp/prizemap-aerodactyl-scoped-frozen/RESEARCH.md` provides current real-engine focused evidence and measured six-source cost. No Android result has been established.
